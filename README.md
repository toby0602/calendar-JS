# My Calendar

使用原生 HTML、CSS、JavaScript 製作的自適應月曆，不需要框架或建置流程。

展示網站：https://toby0602.github.io/calendar-JS/

## 使用方式

直接開啟 `index.html`，或用任意靜態伺服器提供專案目錄。建議固定使用同一個網址與瀏覽器，避免因來源不同而看到不同的儲存資料。

- 點選日期新增／編輯每日記事，每天一筆，最多 2,000 字元。
- 日期格以小字顯示農曆；節日當天以節日名稱取代格內農曆，點選日期可查看完整農曆與節日名稱。
- 淡暖色背景與「休」標記表示行政院人事行政總處辦公日曆表的休假日（含週末與補假）；「班」表示官方辦公日曆列出的週末補行上班日。
- 使用月份箭頭切換月份；點選月曆左上角的年月可在彈窗中直接選擇其他年份與月份。「今天」回到當月，「記下今天」直接開啟今日記事。
- 支援 12 種主題；記事與主題會保存在瀏覽器 localStorage。
- 月曆外使用左右方向鍵切換月份；輸入記事時方向鍵保留原本的文字編輯用途。
- 記事編輯器支援 Ctrl / Command + Enter 儲存；Escape、取消或關閉按鈕放棄此次未儲存的修改。

資料只存在目前瀏覽器，沒有上傳或跨裝置同步。清除網站資料會移除記事與設定。瀏覽器禁止儲存或空間不足時，畫面會顯示錯誤並保留尚未儲存的文字。

農曆由瀏覽器的 `Intl` 中國曆計算，並以台灣時區判斷日期；不支援此曆法的瀏覽器仍可使用西曆月曆。節日是文化日期，與休假日分開標示。清明日期在 2000–2099 年使用節氣近似公式，跨年代或個別年份請以官方公告為準。

休假日資料取自[行政院人事行政總處提供的政府行政機關辦公日曆表 CSV](https://data.gov.tw/dataset/14718)，目前內建 2025 年修正版、2026 年與 2027 年。只在有完整官方資料的年份顯示休假標記；其他年份會提示「此年份尚無官方休假資料」。資料適用於政府行政機關，其他職場的排班與休假可能不同。直接開啟 `index.html` 也能使用，無須執行時連線。

更新資料時，將新的官方 CSV 以 UTF-8 編碼存成 `data/dgpa-YYYY.csv`，執行 `node scripts/build-holidays.cjs` 重新產生 `js/holidays.js`。產生程式會檢查日期、重複列及整年度的完整性。

## 檔案分工

- `index.html`：頁面結構、月曆與原生 dialog 對話框。
- `css/main.css`：基礎樣式、主題變數、共用元件。
- `css/current-day.css`：今日資訊側欄。
- `css/calendar.css`：月曆與本月記事列表。
- `css/modal.css`：記事與主題對話框。
- `css/portrait.css`：依視窗寬度調整手機、平板與桌機版面，含低高度橫向畫面。
- `js/updateDate.js`：日期運算、月曆渲染、月份導覽與初始化。
- `js/lunar.js`：農曆日期與台灣常見節日標記。
- `data/dgpa-*.csv`：官方辦公日曆表來源資料；`js/holidays.js` 是轉換後的瀏覽器資料。
- `js/postIts.js`：記事編輯、本機儲存與輸入驗證。
- `js/changeTheme.js`：主題選項、CSS 變數與設定儲存。

月曆選取使用本地年月日，農曆轉換以台灣時區判斷日期。記事以文字節點渲染，不解讀使用者輸入的 HTML。正式頁面不載入外部字型、圖示套件或其他第三方腳本。

## 驗證

`tests/calendar.cjs` 使用 Node.js 與 Playwright 啟動臨時本機伺服器，預設以已安裝的 Microsoft Edge 無頭模式執行。需讓 Node.js 能解析 `playwright` 套件（本機安裝或設定 `NODE_PATH`），再執行：

```sh
node tests/calendar.cjs
```

可透過 `BROWSER_CHANNEL=chrome` 改用 Chrome。測試不會修改使用者的瀏覽器資料，截圖存放於系統暫存目錄。

涵蓋 320–1920px 共 10 組尺寸、橫向畫面、對話框邊界、農曆與節日日期、官方休假日與補行上班日、閏年／跨年、記事新增編輯刪除、重載持久化、HTML 文字安全、鍵盤操作隔離、主題持久化，以及儲存失敗與資料損毀處理。
